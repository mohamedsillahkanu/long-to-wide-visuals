Common Use Cases

The Long to Wide converter is essential for preparing data for analysis, dashboards, and reporting.

Time Series Data
Convert yearly/monthly data to columns (e.g., Cases_Jan, Cases_Feb...)
DHIS2 Indicator Data
Pivot indicator names to columns for multi-indicator analysis
Survey Responses
Convert question responses from rows to columns per respondent
Before/After Comparisons
Create Pre_value and Post_value columns for intervention analysis

Key Features

The tool handles complex pivoting scenarios with flexible configuration options.

Auto-Detection - Finds year, period, value columns
Custom Separators - Underscore, dash, dot, or none
Missing Value Fill - Empty, NA, 0, or custom
Multiple ID Columns - Group by multiple fields
Live Preview - See column names before converting
Unique Values Display - Shows pivot value options
Tip: The tool shows unique values from your pivot column before conversion, so you know exactly what new columns will be created (e.g., 2022, 2023, 2024 → 3 new columns).
